# 🚗 Find-Ur-Car

A simple yet effective **Car Finder Web App** that helps you discover the best cars within your **budget range**. Just enter your minimum and maximum budget, and get a list of cars that fit perfectly.  

---

## ✨ Features

- 💸 **Budget-Based Search** – Enter your price range to find matching cars.  
- 📊 **Smart Data Filtering** – Uses Pandas to process and filter car data accurately.  
- 📂 **CSV-Based Dataset** – Car details like brand, model, and price are stored in a CSV file.  
- 📱 **Responsive Web App** – Built with Flask and Bootstrap, works smoothly on any device.  

---

## 🛠 Tech Stack

**Backend**: Python (Flask)  
**Frontend**: HTML, CSS, Bootstrap  
**Data Handling**: Pandas  
**Database**: CSV dataset (Brand, Model, Price Range)
